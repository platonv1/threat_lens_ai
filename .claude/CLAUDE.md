# CLAUDE.md

## Project Overview

You are assisting in the development of **AI Internet Safety Center**, a local-first prototype that detects phishing websites, suspicious URLs, scam emails, SMS messages, QR codes, and screenshots.

This project is intended for learning and demonstration purposes and must run entirely on a local machine.

## Objectives

- Build a working prototype.
- Prefer open-source and free tools.
- Avoid paid APIs unless explicitly approved.
- Keep the architecture simple and maintainable.
- Design so cloud migration is possible later.

## Development Principles

- Think before writing code.
- Explain major architectural decisions.
- Build features incrementally.
- Keep business logic separate from API routes.
- Write reusable services.
- Prefer readability over cleverness.
- Avoid over-engineering.

## Preferred Technologies

- Next.js
- TypeScript
- TailwindCSS
- FastAPI
- PostgreSQL
- SQLAlchemy
- Ollama
- EasyOCR
- Docker Compose

## Coding Standards

- Use type hints.
- Validate all API inputs.
- Use environment variables.
- Follow REST conventions.
- Handle errors gracefully.
- Keep functions focused.

## Workflow

For each feature:

1. Explain the design.
2. Implement backend.
3. Implement frontend.
4. Write tests.
5. Update documentation.
6. Update SESSION.md.

Never generate the entire application at once.
