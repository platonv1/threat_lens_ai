# Product Requirements Document

## Product Name

Cyber Scam Shield Assistant AI

## Goal

Create a local web application that helps users identify potentially malicious websites, emails, screenshots, QR codes, and SMS messages using AI and threat analysis.

## Target Users

- General users
- Students
- Cybersecurity learners

## Features

- URL Scanner
- Screenshot Scanner
- Email Scanner
- QR Code Scanner
- AI-generated explanation
- Risk score
- Scan history

## Success Criteria

- Runs locally.
- No paid APIs required.
- Fast response time.
- Easy to understand results.
